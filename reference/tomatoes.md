# FRED Tomato data

A subset of the time series APU0000712311 from FRED, data on tomato
prices from 2016 to 2026

## Usage

``` r
tomatoes
```

## Format

### `lettuce`

A data frame with 119 rows and 5 columns:

- date:

  a Date object with the data of the data

- series_id:

  APU0000712311, tomato series

- value:

  the average price of tomatoes

- realtime_start, realtime_end:

  The date the data was downloaded

## Source

<https://fred.stlouisfed.org/series/APU0000712311>
